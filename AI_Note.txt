2. Design advice for the implementation
---------------------------------------

- Runtime state: Env as an immutable map from names to Ref (rho), Ref as a
  mutable location, and the store sigma as the set of all Refs. Fixed the Ref
  class so its value is a settable property.
- Outcome as a record hierarchy (O_Normal | O_Ret(Value)) instead of an enum
  with a nullable value.
- Closures hold a block body, so lambdas (wrapped as {Ret e;}) and functions
  share one representation.
- Where to keep Delta (built once in P-Prog, kept out of rho), and ways to pass
  it to E_Field.
- Statement execution must return (Outcome, Env) so S_Decl can extend the
  environment; blocks discard the returned environment (scoping).
- Types are erased at run time: S_Decl, E_Lambda and Param keep their types for
  the type checker only; runtime type checks are not part of the rules.
- Pointed out issues to decide or document:
    - Nat subtraction wraps around in C# (choose error or floor at zero);
    - && and || are strict, not short-circuiting, and are missing from the
      report's grammar;
    - the recursive S_While will overflow the stack on long loops;
    - records containing lists (T_Func, V_Record) compare lists by reference.

      S_Return);

      shadowing);

- Reviewed P_Prog: closures must capture the finished global environment
  (two passes: placeholder Refs, then fill), and found the parameter
